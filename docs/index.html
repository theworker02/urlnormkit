Overview

Normalize URLs with stable host casing, default-port stripping, and sorted query keys. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/urlnormkit.git
cd urlnormkit
node src/cli.js --help
node --test
