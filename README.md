# urlnormkit

Normalize URLs with stable host casing, default-port stripping, and sorted query keys.

**Site:** https://theworker02.github.io/urlnormkit/

## Install / run

```bash
git clone https://github.com/theworker02/urlnormkit.git
cd urlnormkit
node src/cli.js
node --test
```
